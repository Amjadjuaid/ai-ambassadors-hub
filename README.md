# بوابة سفراء الذكاء الاصطناعي — AI Ambassadors Hub (نسخة طيار Pilot)

تطبيق ويب خفيف بدون أي أدوات بناء (build tools) — ملفات HTML/CSS/JS عادية.
قاعدة البيانات: Firebase Firestore (مجاني). الاستضافة: أي استضافة ثابتة مجانية.

---

## 1) إنشاء قاعدة بيانات Firebase (٥ دقائق)

1. افتح https://console.firebase.google.com وسجّل الدخول بحساب Google.
2. **Add project** → اختر اسمًا (مثال: `ai-ambassadors-hub`) → أكمل الخطوات (يمكن تعطيل Google Analytics، غير مطلوب).
3. من القائمة الجانبية: **Build → Firestore Database** → **Create database** → اختر أي موقع قريب (مثال: `eur3` أو `me-central1` إن توفر) → ابدأ في **وضع الاختبار (test mode)**.
4. بعد الإنشاء، افتح تبويب **Rules** داخل Firestore، واستبدل المحتوى بمحتوى ملف `firestore.rules` المرفق هنا، ثم اضغط **Publish**.
5. من **Project settings** (⚙️ بجانب Project Overview) → مرّر لأسفل إلى **Your apps** → اضغط أيقونة الويب `</>` → سمِّ التطبيق (مثال: `web`) → **Register app**.
6. ستظهر لك بيانات إعداد (`firebaseConfig`) تشبه:
   ```js
   const firebaseConfig = {
     apiKey: "AIza...",
     authDomain: "ai-ambassadors-hub.firebaseapp.com",
     projectId: "ai-ambassadors-hub",
     storageBucket: "ai-ambassadors-hub.appspot.com",
     messagingSenderId: "...",
     appId: "..."
   };
   ```
7. افتح ملف **`firebase-config.js`** في هذا المجلد، واستبدل القيم الوهمية بهذه القيم الحقيقية. احفظ الملف.

هذا كل شيء من جهة قاعدة البيانات — لا حاجة لأي كود خادم (backend) إضافي.

---

## 2) نشر التطبيق (استضافة مجانية بدون سطر أوامر)

أسهل طريقة: **Netlify Drop** (سحب وإفلات، بدون حساب حتى للتجربة الأولى، ويُفضّل عمل حساب مجاني لرابط ثابت).

1. افتح https://app.netlify.com/drop
2. اسحب مجلد `ai-ambassadors-hub` بالكامل (بعد تعديل `firebase-config.js`) وأفلته في الصفحة.
3. خلال ثوانٍ ستحصل على رابط مباشر مثل: `https://xxxxx.netlify.app` — هذا هو الرابط غير المُدرج (unlisted) الذي تشاركه مع الموظفين.
4. لتغييره لاحقًا: أنشئ حساب Netlify مجاني، واسحب المجلد المحدَّث لنفس الموقع لتحديثه، ويمكنك أيضًا تخصيص الاسم الفرعي من إعدادات الموقع.

**بدائل أخرى** تعمل بنفس الطريقة (رفع مجلد ثابت): GitHub Pages، Vercel، Firebase Hosting (يتطلب CLI).

---

## 3) كود وصول مساحة السفراء

الكود الافتراضي محفوظ في `constants.js`:
```js
const AMBASSADOR_ACCESS_CODE = "AMB-2026";
```
غيّره لأي كود تختاره قبل النشر، وشاركه مع السفراء العشرة خارج نطاق الرابط نفسه (مثال: عبر بريد أو Teams). **تنبيه مهم**: هذا الكود يخفي واجهة الاستخدام فقط لمنع الدخول العرضي — وليس طبقة حماية حقيقية للبيانات (راجع التنبيه في `firestore.rules`). لا تُدخل بيانات سرية في أي طلب أو ملاحظة.

---

## 4) البيانات التجريبية (Demo Data)

عند أول تشغيل لقاعدة بيانات فارغة، يزرع التطبيق تلقائيًا: ١٠ سفراء، ~١٨ طلبًا تجريبيًا بحالات متنوعة، و٣ تجمّعات فرص متكررة — كل ذلك معلَّم بشارة "بيانات تجريبية" في الواجهة.

لحذف كل البيانات التجريبية عند الانتقال للاستخدام الفعلي: **مساحة السفراء → لوحة المتابعة → مسح البيانات التجريبية** (يتطلب كود وصول السفراء). ستحتاج بعدها لإضافة أسماء السفراء الحقيقيين يدويًا في Firestore (تبويب Firestore Database → مجموعة `ambassadors`) بنفس بنية السجلات التجريبية.

## 5) بنية الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | هيكل الصفحة والتحميل |
| `styles.css` | كل التصميم (تصميم احترافي بسيط، RTL) |
| `constants.js` | القوائم الثابتة (الحالات، التصنيفات، إلخ) — عدّل هنا أولًا لأي تغيير في الخيارات |
| `firebase-config.js` | بيانات ربط مشروعك على Firebase (تحتاج تعديلها فقط) |
| `firebase-init.js` | تهيئة الاتصال بـ Firebase |
| `data.js` | **طبقة الوصول للبيانات فقط** — كل استدعاءات قاعدة البيانات تمر من هنا. لاستبدال Firebase لاحقًا بقاعدة بيانات داخلية للمؤسسة، عدّل هذا الملف فقط دون المساس بباقي التطبيق |
| `seed-data.js` | البيانات التجريبية ومنطق الزرع التلقائي |
| `app.js` | التوجيه (routing) وكل واجهات العرض والتفاعل |

---

## 6) قيود معروفة (طيار وليس نظامًا إنتاجيًا)

- **لا يوجد تسجيل دخول حقيقي**: أي شخص يملك الرابط يمكنه تقنيًا قراءة كل الطلبات (بما فيها الملاحظات الداخلية للسفراء) عبر أدوات المطوّر في المتصفح، حتى دون إدخال كود السفراء. الكود يخفي الواجهة فقط. هذا مقصود بناءً على طلب تبسيط التطبيق (بدون SSO أو مصادقة معقّدة)؛ إن احتجت منع ذلك فعليًا في V2 فالحل هو مصادقة حقيقية (Firebase Auth) لا يمكن إضافتها بدون كسر مبدأ "بدون مصادقة معقّدة".
- **لا نسخ احتياطي تلقائي**: البيانات في Firestore تبقى ما لم تُحذف يدويًا؛ لأخذ نسخة احتياطية استخدم تصدير Firestore من الكونسول.
- **حصة Firebase المجانية (Spark)**: سخية جدًا لحجم ١٠ سفراء وبضع مئات الطلبات (٥٠ ألف قراءة و٢٠ ألف كتابة يوميًا مجانًا) — كافية بوضوح لهذا الطيار.
